# 实盘验证策略推荐 — 完整研究综述

> **文档版本**：v1.0（2026-05-19）
> **基于**：从原始策略爆仓到 4 标的 3 年回测的完整研究过程（30+ 个迭代里程碑）
> **结论**：经实证验证的最推荐实盘验证方案

---

## 一、研究历程关键发现总览

### 1.1 被否定的方向

经过实测，以下设想**不可用**或**反作用**：

| 方向 | 实测结果 | 结论 |
|---|---|---|
| **本金 10 万** | 黄金爆仓（保证金不足） | ❌ 至少 50 万 |
| **多数据源 5m+15m 趋势** | 框架被偷偷降采样到 15m，5m 粒度丢失 | ❌ 改用 5m 内部合成 MA |
| **超时强平 + 趋势反转强平** | 把好仓也切了，盈亏比从 1.98 跌到 0.72 | ❌ 不能简单加保险 |
| **成交量过滤** | 实测两个时间段都拖累绩效 | ❌ 默认关闭 |
| **DC 指标过滤替代 MA240** | 跨品种平均不如 MA240 | ❌ 不切换 |
| **TYPE2/TYPE4 信号** | 5m 上 0 次触发（即使降阈值到 1.1）| ❌ 死代码 |
| **TYPE1B 经典二买** | 信号增 35% 但盈亏比从 3.27 → 1.11 | ⚠️ 默认关闭 |
| **ma_period=120 默认值** | au/cu 大幅改善，i/rb 崩盘 | ❌ 用 240 跨品种更稳 |

### 1.2 被验证的方向

以下改动**有显著正向作用**：

| 方向 | 实测结果 | 推荐度 |
|---|---|---|
| **15m 等价 MA240 趋势过滤** | 单一最重要改进，过滤 95% 噪声信号 | ✨✨✨ |
| **缠论"同走势 ≤ 2 次"原则** | 由亏转盈的关键改动 | ✨✨✨ |
| **TYPE3（三买/卖）信号** | 占总信号 60%+，胜率最高 | ✨✨✨ |
| **本金 50 万** | 避免爆仓，夏普显著改善 | ✨✨ |
| **跨品种独立赛道分散** | 风险摊薄，回撤显著降低 | ✨✨ |

## 二、跨品种 + 跨时间真实画像

经过 2022-2024 三年纵向 + 多品种横向测试，得出"哪些品种值得交易"：

| 品种 | 赛道 | 3 年年化 | 夏普 | 评价 |
|---|---|---:|---:|---|
| **sc888 原油** | 能化 | **+21.38%** | **+0.60** | ✨ 跨周期最稳，唯一三年都赚 |
| au888 黄金 | 贵金属 | +1.07% | -0.15 | ✓ 持平、回撤可控 |
| cu888 铜 | 有色 | -5.28% | -0.67 | ✗ 单年好但纵向亏 |
| m888 豆粕 | 农产品 | -1.88% | -2.68 | ✗ 不适合趋势策略 |
| i888 铁矿 | 黑色 | (单年 -0.75%) | (-0.02) | ✗ 震荡品种 |
| rb888 螺纹 | 黑色 | (单年 +0.92%) | (+0.07) | ✗ 几乎不动 |

**核心洞察**：
- **能源 / 贵金属** 趋势属性最强 → 推荐
- **农产品 / 黑色** 短期事件驱动 → 不推荐
- **股指 IM** 数据不完整无法判断 → 待观察

## 三、推荐实盘验证方案

### 3.1 资产池（核心 + 卫星 = 2 标的）

| 仓位权重 | 标的 | 理由 |
|---:|---|---|
| **70%** | **sc888 原油**（核心）| 3 年验证夏普 +0.60、年化 +21% |
| 30% | au888 黄金（卫星）| 风险对冲，回撤独立于原油 |

资金分配示例（50 万本金）：
- 原油 35 万
- 黄金 15 万

### 3.2 策略参数（已调优锁定）

```python
strategy_params = {
    # ---- 缠论核心 ----
    'min_bi_len': 5,
    'golden_ratio': 1.2,                  # 已降低但仍不触发，可保留
    'v_reversal_power_ratio': 1.1,        # 同上
    'break_tolerance': 0.002,

    # ---- 风控 ----
    'atr_period': 14,
    'atr_stop_multiplier': 2.5,           # 5m 噪声大，放宽
    'base_volume': 1,
    'use_structure_stop': True,
    'signal_cooldown': 6,                 # 30 分钟冷却

    # ---- 趋势过滤（最重要）----
    'use_trend_filter': True,
    'trend_filter_type': 'ma',
    'trend_ma_period': 240,               # 跨品种稳健
    'trend_buffer': 0.005,

    # ---- 缠论"买卖点不超买"原则 ----
    'max_trades_per_trend': 2,

    # ---- 关掉以下（实测拖累）----
    'use_volume_filter': False,
    # （TYPE1B 在代码里加了但优先级低，不主动关）
    # （TYPE2/TYPE4 阈值低但不触发，等同关闭）

    'kline_period': '5m',
}
```

### 3.3 风控规则（必须）

| 规则 | 触发条件 | 动作 |
|---|---|---|
| **单笔风险上限** | 单笔最大可亏损 ≤ 账户 1% | 减仓 |
| **单标的回撤熔断** | sc 或 au 回撤 > 15% | 暂停该标的 1 周 |
| **总账户熔断** | 整体回撤 > 25% | 全部清仓，复盘 |
| **数据源故障** | API 30s 无响应 | 切到 SIMNOW 备份数据 |
| **隔夜风险** | 周五收盘前 | 减仓或平仓夜盘空头 |

## 四、实盘验证三阶段（4-6 个月）

### 阶段 1：纸盘 30 天（SIMNOW）

**目标**：验证基础设施可用

- 连接 CTP SIMNOW，跑 sc + au 双标的
- 监控指标：
  - 每日信号产出是否符合回测预期（sc 约 8 个/月、au 约 6 个/月）
  - API 中断频率、重连成功率
  - 实际成交跟回测开盘价的滑点
- **通过条件**：30 天无系统级故障，信号数量在预期 ±30% 内

### 阶段 2：极小本金实盘 60 天

**目标**：验证滑点和真实成交质量

- 本金 5 万元（不分仓，全押 1 标的）
- **先做 sc888，原油每手 1000 桶 × 0.1 price tick = 100 元/tick**
- 仓位：1 手起步
- 监控：
  - 实际滑点 vs 回测假设
  - 成交回报延迟
  - 夜盘暂停的影响
- **通过条件**：60 天累计净盈亏跟回测同期偏差 < 20%

### 阶段 3：正式实盘 90 天

**目标**：验证完整策略生命周期

- 本金 50 万，按 70 / 30 分配 sc / au
- 跑完一个完整季度（看趋势品种的强/弱周期切换）
- 每月写复盘报告：实际信号、未触发的信号、错过的机会
- **通过条件**：90 天年化化收益 > +5%（不要求 +21% 那么乐观），最大回撤 < 18%

## 五、关键风险提示

### 必须接受的"已知输"

1. **震荡市必然亏**：策略本质是 trend-following。如果 sc 进入像 2024 铁矿那样的窄幅震荡，策略一定亏，且回撤不可避免。**不要在那段时期加仓拼底**。

2. **5m 噪声永远存在**：30% 胜率是统计平均，会出现连续 10 笔亏损。**单一品种连续 15 笔亏损前不要怀疑策略**（统计上 5 个标准差才算异常）。

3. **API 中断会导致仓位失控**：建议本机 + 备份机双服务器，并配置 CTP 通过托管服务器（深圳/上海机房）连接。

### 需要持续监控的指标

| 指标 | 健康范围 | 异常表现 → 行动 |
|---|---|---|
| 胜率 | 28% - 35% | < 25% → 暂停复盘 |
| 盈亏比 | > 2.0 | < 1.5 → 检查止损/趋势过滤 |
| 信号触发率 | 跟回测同期 ±30% | 偏离 → 检查数据源 |
| 单标的回撤 | < 15% | > 15% → 强制熔断 |
| 30 日夏普 | > 0 | 连续 2 月 < 0 → 全停 |

## 六、什么时候应该放弃策略

满足任一条即应**永久停止**，不是简单暂停：

1. **6 个月累计亏损 > 25%**（与回测最坏情况差距过大）
2. **某品种 3 个月连续 0 信号**（说明市场结构变了）
3. **滑点超过回测假设 3 倍**（流动性变差）
4. **策略胜率长期 < 22%**（信号检测机制失效）
5. **黑天鹅事件后回撤 > 35%**（如 2020 原油负价格、2024 黄金大跳水）

---

## 七、还可继续做的事（实盘后再迭代）

按优先级排序：

1. **加波动率自适应仓位** — 高 ATR 时减仓，低 ATR 时正常
2. **加止盈机制** — 当前只有止损，没有主动止盈，可能错过见顶
3. **多周期共振** — 5m 信号 + 15m / 30m 方向确认（要解决多源对齐黑盒）
4. **机器学习信号过滤** — 用历史信号特征训练分类器过滤 false positive
5. **拉更长历史**（2018-2021）做样本外验证

## 八、最终建议

### 先做最小可行版本

- ✅ 2 标的（sc + au）
- ✅ 50 万本金
- ✅ 已锁定参数
- ✅ 严格风控

### 不要做的事

- ❌ 不要为了"多元化"加入农产品/股指（实测无效）
- ❌ 不要尝试加密货币（数据接入有挑战、波动率太高、监管不确定）
- ❌ 不要在 1 个月内频繁改参数（破坏统计意义）
- ❌ 不要押满 100% 仓位（流动性事件会让你出不来）

### 6 个月后再决定是否扩展

- 通过 = 加入 bu888（沥青）/ p888（棕榈油）等趋势性强的品种
- 通过 + 1 = 尝试多周期共振或 ML 过滤
- 失败 = 回到研究状态，不要硬撑

**最终一句话总结**：经过 30 多次实证迭代，**最稳健可实盘的版本就是 sc + au 双标的、MA240 趋势过滤、缠论同走势 2 次上限的简单组合。所有"看起来更好"的复杂改进都需要先在跨品种 + 跨时间双重验证后才能上。**
