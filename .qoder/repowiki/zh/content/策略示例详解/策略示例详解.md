## 简介

SSQuant是一个专业的期货量化交易框架，提供了19个完整的策略示例，涵盖从基础到高级的各类交易策略。该框架支持统一的策略代码在回测、SIMNOW模拟和实盘CTP三种环境下运行，为量化交易者提供了完整的开发和部署解决方案。

框架的核心特性包括：
- **统一策略框架**：一套代码三处运行
- **强大的交易功能**：自动开平仓管理、智能算法交易
- **丰富的策略示例**：涵盖趋势、套利、轮动、期权、机器学习等类型
- **多品种多周期支持**：同时交易多个品种，使用不同周期数据

## 核心组件

### 策略API系统

SSQuant的策略API提供了统一的接口，使策略开发者能够专注于交易逻辑的实现，而不需要关心底层的交易细节。

核心API功能包括：
- **数据获取**：收盘价、开盘价、最高价、最低价、成交量等
- **持仓查询**：净持仓、多头持仓、空头持仓、详细持仓信息
- **交易操作**：买入开仓、卖出平仓、卖出开仓、买入平仓、全部平仓、反手
- **参数管理**：策略参数获取、日志记录
- **多数据源支持**：支持同时交易多个品种和周期

### 统一运行器

统一运行器是SSQuant的核心组件，它负责在不同的运行模式下执行策略：

```mermaid

Runner->>Strategy : 调用initialize()
Strategy-->>Runner : 初始化完成

Runner->>Strategy : 调用策略函数
Strategy->>Engine : 执行交易指令
Engine-->>Strategy : 返回执行结果
Strategy-->>Runner : 返回状态
end
```

## 详细组件分析

### 基础策略分析

#### 双均线策略

双均线策略是最经典的趋势跟踪策略之一，通过短期均线和长期均线的交叉来产生交易信号。

```mermaid
flowchart TD
Start([开始]) --> GetData[获取收盘价数据]
GetData --> CheckData{数据长度足够?}
CheckData --> |否| Wait[等待更多数据]
CheckData --> |是| CalcMA[计算均线]
CalcMA --> CheckCross{检查均线交叉}
CheckCross --> |金叉| BuySignal[做多信号]
CheckCross --> |死叉| SellSignal[做空信号]
CheckCross --> |无信号| Hold[持有观望]
BuySignal --> CheckPos{检查持仓}
CheckPos --> |空仓或空头| PlaceBuy[下单做多]
CheckPos --> |多头| PlaceBuy
SellSignal --> CheckPos2{检查持仓}
CheckPos2 --> |空仓或多头| PlaceSell[下单做空]
CheckPos2 --> |空头| PlaceSell
PlaceBuy --> End([结束])
PlaceSell --> End
Hold --> End
Wait --> End
```

**图表来源**
- [B_双均线策略.py](file://examples/B_双均线策略.py#L106-L123)

**策略特点**：
- 使用5日和20日均线进行交叉判断
- 支持TICK流驱动和K线驱动两种模式
- 具备基本的风险管理机制

**参数调优建议**：
- 短期均线：3-10日（根据品种波动性调整）
- 长期均线：15-50日（与短期均线形成合理比例）
- 滑点设置：根据品种最小变动价位设置

### 专业策略分析

#### 网格交易策略

网格交易策略适用于震荡市场，在价格波动范围内进行高抛低吸。

```mermaid
flowchart TD
Start([开始]) --> InitGrid[初始化网格]
InitGrid --> GetPrice[获取当前价格]
GetPrice --> CalcLevel[计算网格层级]
CalcLevel --> CheckChange{层级是否变化?}
CheckChange --> |否| Wait[等待]
CheckChange --> |是| CheckDirection{检查交易方向}
CheckDirection --> |价格下跌| BuyGrid[网格买入]
CheckDirection --> |价格上涨| SellGrid[网格卖出]
BuyGrid --> UpdateLevel[更新层级]
SellGrid --> UpdateLevel
UpdateLevel --> GetPrice
Wait --> GetPrice
```

**图表来源**
- [B_网格交易策略.py](file://examples/B_网格交易策略.py#L57-L144)

**网格交易逻辑**：
1. 以首次价格为基准，计算当前价格所在的网格层级
2. 层级下降（价格下跌）→ 买入
3. 层级上升（价格上涨）→ 卖出
4. 支持最大持仓限制

**参数设置建议**：
- 网格间距：根据品种价格合理设置（螺纹钢建议20-50元，黄金建议2-5元）
- 最大持仓：根据资金规模和风险承受能力设定

## 故障排除指南

### 常见问题及解决方案

#### 数据获取问题

**问题**：找不到数据或数据为空
**解决方案**：
1. 检查symbol代码是否正确
2. 验证日期范围的有效性
3. 确认API账号配置正确
4. 检查数据预加载设置

#### 策略执行问题

**问题**：策略不执行或提前返回
**解决方案**：
1. 确保数据长度足够（满足策略参数要求）
2. 检查早期返回语句
3. 添加api.log()进行调试
4. 验证策略参数设置

#### 交易执行问题

**问题**：持仓不正确或交易失败
**解决方案**：
1. 检查order_type设置（回测用next_bar_open，实盘用market）
2. 验证price_tick设置
3. 检查账户资金和保证金
4. 确认CTP连接状态

#### 回测与实盘差异

**问题**：回测和实盘结果差异较大
**解决方案**：
1. 检查复权类型设置
2. 验证滑点设置
3. 确认最小变动价位设置
4. 检查交易费用设置

### 调试技巧

1. **日志记录**：使用api.log()记录关键信息
2. **参数验证**：检查策略参数的有效性
3. **数据验证**：验证输入数据的质量
4. **状态监控**：监控策略执行状态
