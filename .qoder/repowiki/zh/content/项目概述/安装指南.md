## 简介
SSQuant 是一款专业的期货CTP量化交易框架，支持“一套代码三处运行”：回测、SIMNOW模拟交易与实盘CTP交易。本安装指南面向不同用户群体，提供详细的安装步骤、常见问题排查与网络优化建议，帮助您快速完成环境搭建并顺利运行策略。

## 系统要求与环境准备
- 操作系统：Windows 10+（目前仅支持 Windows，Linux 版本待更新）
- Python 版本：3.9 ~ 3.14
- 内存：4GB+
- 网络：稳定连接（实盘/SIMNOW）

此外，框架内置 CTP 6.7.7 ~ 6.7.10 版本，支持 Python 3.9 ~ 3.14，位于 ssquant/ctp/py*/ 目录中。若 Python 版本不在支持范围内，CTP 功能将不可用，回测功能仍可正常使用。

## 安装方式一：使用 pip 安装（推荐）
这是最简单快捷的方式，适用于大多数用户。

- 基础安装
  - 执行命令：pip install ssquant
  - 该命令会从 PyPI 安装最新版本的 SSQuant 框架及其依赖。

- 新手安装指引（解决环境问题）
  - 如果遇到环境索引问题，请按以下步骤操作：
    1) 卸载旧版本：pip uninstall ssquant
    2) 重新安装（推荐使用国内源）：pip install ssquant -i https://pypi.tuna.tsinghua.edu.cn/simple
    3) 获取示例：新手朋友直接通过 pip 安装框架，然后到 [GitHub](https://github.com/songshuquant/ssquant) 或 [Gitee（国内推荐）](https://gitee.com/ssquant/ssquant) 下载 examples/ 目录下的策略示例。
    4) 补充依赖：运行中如果提示缺什么库，直接 pip install 库名 安装即可。

- 安装验证
  - 验证命令：python -c "from ssquant.api.strategy_api import StrategyAPI; print('ssquant 导入成功!')"
  - 若输出“ssquant 导入成功!”，表示安装成功；否则请参考“常见问题排查”。

- 获取示例策略
  - 安装完成后，可直接在 examples/ 目录下找到 19 个策略示例，涵盖趋势、套利、轮动、期权、机器学习等类型。

## 安装方式二：从源码安装
当您需要使用最新开发分支或自定义修改时，可选择从源码安装。

- 准备工作
  - 下载源码压缩包（通常解压后文件夹名为 ssquant-main），或通过 git clone 拉取代码。
  - 打开终端（CMD/PowerShell），进入该文件夹（确保能看到 setup.py 文件）。

- 执行安装
  - 安装命令：pip install -e .
  - 注意：命令最后有一个点 .，代表当前目录，不要漏掉。
  - 文件夹名字（如 ssquant-main）不影响安装，只要目录结构正确即可。

- 验证安装
  - 同样使用上述验证命令，确认 ssquant 可正常导入。

## 安装验证与常见问题排查
- 验证安装成功
  - 执行命令：python -c "from ssquant.api.strategy_api import StrategyAPI; print('ssquant 导入成功!')"
  - 输出“ssquant 导入成功!”即为成功。

- 常见错误：ModuleNotFoundError: No module named 'ssquant'
  - 原因：ssquant 未安装或已被卸载。
  - 解决方法：
    1) 检查是否已安装：pip list | findstr ssquant（Windows）
    2) 如果没有找到，重新安装：
       - 方式一：从 PyPI 安装：pip install ssquant
       - 方式二：从源码安装（在项目目录下执行）：pip install -e .
    3) 再次验证安装成功。

- CTP 功能不可用的提示
  - 当 Python 版本不在支持范围内时，启动时会提示“当前Python x.x 的CTP功能不可用”，回测功能可正常使用。
  - 解决方案：使用支持的 Python 版本（3.9 ~ 3.14）重新安装。

- 运行示例策略验证
  - 可以运行 examples/B_双均线策略.py 进行端到端验证，该示例展示了如何在三种模式（回测/SIMNOW/实盘）之间切换。

## 国内用户网络优化与清华源使用
- 清华源使用方法
  - 安装命令：pip install ssquant -i https://pypi.tuna.tsinghua.edu.cn/simple
  - 该镜像源在国内访问速度较快，适合国内用户使用。

- 其他国内镜像源
  - 除了清华源，还可考虑阿里云、豆瓣、中科大等镜像源，提升下载速度。

- 网络问题解决方案
  - 若仍出现网络不稳定或超时，建议：
    1) 更换镜像源
    2) 使用代理工具（如系统代理或全局代理）
    3) 确保防火墙允许 pip 访问外网
    4) 临时关闭杀毒软件或安全软件，避免误拦截

## 总结
- 推荐使用 pip 安装（ssquant），简单快捷，适合大多数用户。
- 若需要最新功能或自定义修改，可选择从源码安装。
- 安装完成后务必进行验证，确保 ssquant 可正常导入。

- 若遇到 ModuleNotFoundError 等问题，按“常见问题排查”逐步解决。
- 完成安装后，可直接运行 examples/ 目录下的策略示例，体验“一套代码三处运行”的能力。
