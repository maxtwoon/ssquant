# K 线数据库增量更新服务调用说明

SSQuant 框架提供了可复用的 K 线数据库增量更新能力，支持以下三种调用方式：

1. **Python 模块导入**（推荐同 Python 项目使用）
2. **命令行调用**（适合脚本、定时任务）
3. **HTTP API 服务**（适合跨语言项目远程调用）

---

## 一、Python 模块导入

### 1. 安装依赖

确保已安装 ssquant 及其依赖：

```bash
cd ssquant
pip install -e .
# 或
pip install -r requirements.txt
```

### 2. 调用示例

```python
from ssquant.data.update_service import update_kline_db

# 更新整个数据库
result = update_kline_db(
    db_path=r"D:\BaiduNetdiskDownload\新数据库\ssquant数据库_20260425\kline_data.db",
    end_date=None,  # 默认更新到今天
)

print(f"总表数: {result['total_tables']}")
print(f"成功: {result['success_count']}")
print(f"失败: {result['fail_count']}")
print(f"总新增: {result['total_added']}")
print(f"日志: {result['log_path']}")

# 带进度回调
result = update_kline_db(
    db_path=r"D:\BaiduNetdiskDownload\新数据库\ssquant数据库_20260425\kline_data.db",
    progress_callback=lambda idx, total, table, res: print(
        f"[{idx}/{total}] {table}: 新增 {res['added']} 条"
    ),
)

# 只更新指定表
result = update_kline_db(
    db_path=r"D:\BaiduNetdiskDownload\新数据库\ssquant数据库_20260425\kline_data.db",
    tables_filter=['rb888_1M_raw', 'au888_1M_raw'],
)
```

### 3. 返回结构

```python
{
    'success': bool,              # 是否全部成功
    'db_path': str,               # 数据库路径
    'end_date': str,              # 更新截止日期
    'total_tables': int,          # 处理的表总数
    'success_count': int,         # 成功表数
    'fail_count': int,            # 失败表数
    'total_added': int,           # 总新增记录数
    'details': List[Dict],        # 每张表的详细结果
    'log_path': str,              # CSV 明细日志路径
}
```

## 二、命令行调用

### 1. 进入项目目录

```bash
cd d:\repo\ssquant
```

### 2. 更新默认数据库

```bash
python update_kline_db.py
```

### 3. 指定数据库路径

```bash
python update_kline_db.py --db-path "D:\data\kline_data.db"
```

### 4. 指定截止日期和表

```bash
python update_kline_db.py \
  --db-path "D:\data\kline_data.db" \
  --end-date 2026-07-07 \
  --table rb888_1M_raw \
  --table au888_1M_raw
```

## 三、HTTP API 服务

适合非 Python 项目（如 Java、C#、Go、JavaScript 等）通过 HTTP 调用。

### 1. 安装依赖

```bash
pip install fastapi uvicorn
```

已在 `requirements.txt` 中声明为可选依赖。

### 2. 启动服务

```bash
cd d:\repo\ssquant
python ssquant/data/update_api.py
```

默认监听 `http://0.0.0.0:8000`，也可使用 uvicorn 启动：

```bash
uvicorn ssquant.data.update_api:app --host 0.0.0.0 --port 8000
```

### 3. 接口说明

#### 健康检查

```http
GET http://127.0.0.1:8000/health
```

响应：

```json
{
  "status": "ok",
  "time": "2026-07-07T09:38:42.793497"
}
```

#### 执行更新

```http
POST http://127.0.0.1:8000/update
Content-Type: application/json

{
  "db_path": "D:\\BaiduNetdiskDownload\\新数据库\\ssquant数据库_20260425\\kline_data.db",
  "end_date": "2026-07-07",
  "tables": ["rb888_1M_raw", "au888_1M_raw"]
}
```

说明：
- `db_path`：**必填**，目标 SQLite 数据库路径
- `end_date`：可选，默认今天
- `tables`：可选，不传则更新全部 K 线表

响应：

```json
{
  "success": true,
  "db_path": "D:\\BaiduNetdiskDownload\\新数据库\\ssquant数据库_20260425\\kline_data.db",
  "end_date": "2026-07-07",
  "total_tables": 2,
  "success_count": 2,
  "fail_count": 0,
  "total_added": 50000,
  "log_path": "D:\\BaiduNetdiskDownload\\新数据库\\ssquant数据库_20260425\\update_log_20260707_093905.csv",
  "details": [...]
}
```

### 4. Python 调用示例

```python
import requests

payload = {
    "db_path": r"D:\BaiduNetdiskDownload\新数据库\ssquant数据库_20260425\kline_data.db",
    "tables": ["rb888_1M_raw"],
}
resp = requests.post("http://127.0.0.1:8000/update", json=payload)
print(resp.json())
```

### 5. JavaScript / Node.js 调用示例

```javascript
const resp = await fetch('http://127.0.0.1:8000/update', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    db_path: 'D:\\BaiduNetdiskDownload\\新数据库\\ssquant数据库_20260425\\kline_data.db',
    tables: ['rb888_1M_raw'],
  }),
});
const data = await resp.json();
console.log(data);
```

## 四、表名识别规则

服务会自动识别符合以下格式的 K 线表：

```
{symbol}_{period}_{adjust}
```

例如：

- `rb888_1M_raw`：螺纹钢主力连续合约，1 分钟，不复权
- `ag777_5M_raw`：白银次主力连续合约，5 分钟，不复权
- `au2608_15M_raw`：黄金 2608 合约，15 分钟，不复权

支持的 `period`：`1M`, `5M`, `15M`, `30M`, `1H`, `4H`, `D`, `W`, `M` 等  
支持的 `adjust`：`raw`（不复权）、`hfq`（后复权）、`qfq`（前复权）

## 五、注意事项

1. **API 账号**：调用前需确保 `ssquant/config/trading_config.py` 中已配置有效的 `API_USERNAME` 和 `API_PASSWORD`。
2. **备份**：更新前建议对原数据库进行备份，尤其是全量更新场景。
3. **耗时**：全库 1395 张表增量更新约需 30-40 分钟，具体时间取决于网络和数据量。
4. **并发**：HTTP 服务使用单线程执行更新，避免对 data_server 造成过大压力。
5. **日志**：每次更新会自动生成 `update_log_YYYYMMDD_HHMMSS.csv` 明细文件，保存在数据库同级目录。
